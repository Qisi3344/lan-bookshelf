# 澜的小书架 🦉

小灰狼和澜一起收集的好东西：好用的 skill、素材库、参考站。要用的时候来这里翻～

直接用浏览器打开 `index.html` 就能看（不需要服务器）。点一本书，它会翻开告诉你它是什么、什么时候用、去哪里找。

## 结构
- `index.html` — 书架页面
- `css/style.css` — 木头书架、3D 书、翻开的书
- `js/books.js` — **书目**（加新书只改这里）
- `js/shelf.js` — 摆书、翻书、小猫头鹰眨眼

## 加一本新书
在 `js/books.js` 对应那一层的 `books` 里加一条：

```js
{ title: "书名", spine: "书脊上的短名(可选)", sub: "副标题", icon: "📖",
  color: "#5f9e8f", h: 170, w: 50,
  desc: "它是什么", when: "什么时候翻开它",
  link: "https://...(可选)", added: "2026-10-27" }
```

想开新的一层，就在 `SHELVES` 里加一个 `{ id, name, note, books: [] }`。
